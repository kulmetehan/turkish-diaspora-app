# Documentation Archive

This directory contains archived documentation that is no longer actively maintained but kept for historical reference.

## Structure

- **`epics/`** - Completed epics and feature documentation
- **`legacy/`** - Legacy document files (e.g., .docx files from early project stages)
- **`implementation-plans/`** - Outdated implementation plans and progress documents

## Why Archive?

Documentation is archived when:
- Features are completed and no longer need active documentation
- Documents are superseded by newer, more accurate documentation
- Files are outdated but contain historical context worth preserving

## Current Status Documentation

For current project status and progress, see:
- [`PROJECT_PROGRESS.md`](../../PROJECT_PROGRESS.md) - Authoritative project status and milestones
- [`PROJECT_CONTEXT.md`](../../PROJECT_CONTEXT.md) - Current architecture and context
- [`Docs/README.md`](../README.md) - Documentation index

## Archive Policy

- Archived documents are read-only
- Do not update archived documents directly
- If historical information is needed, reference the archive but update current documentation
- Consider moving completed epics to archive after feature completion
